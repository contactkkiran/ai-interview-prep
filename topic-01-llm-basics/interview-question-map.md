# Interview Question Map For Topic 1

Topic 1 does not fully solve all uploaded questions, but it is the foundation under them.

## Directly Connected

1. General AI/LLM Engineering Interview Topics
   - Learn: LLMs, Transformers, embeddings, hallucinations, evaluation.

2. LLM Inference System Design / Model Serving Optimization
   - Learn first: tokens, context window, latency, output length.
   - Later topics needed: batching, KV cache, quantization, GPUs.

3. Semantic Caching For LLM Applications
   - Learn first: embeddings, semantic similarity, tokens, cost.
   - Later topics needed: cache thresholds, TTL, invalidation.

4. RAG For Tables And Structured Documents
   - Learn first: context window, embeddings, retrieval, grounding.
   - Later topics needed: document parsing, chunking, table-aware retrieval.

5. RAG Cache Invalidation / Knowledge Refresh
   - Learn first: grounding, context, cached answers.
   - Later topics needed: versioning, refresh workflows.

6. Multi-hop, Multi-document Retrieval In RAG
   - Learn first: retrieval, context construction, embeddings.
   - Later topics needed: query decomposition and iterative retrieval.

7. Repository-scale Code Understanding For Coding Agents
   - Learn first: context window limits, embeddings, retrieval.
   - Later topics needed: ASTs, symbol graphs, repo indexes.

8. AI Agent Tool Selection / Tool Routing
   - Learn first: prompts, tool descriptions, model reasoning limits.
   - Later topics needed: agent tracing, evals, tool schemas.

## Less Direct But Still Important

1. AI Agent Security / Financial Guardrails
   - Learn first: prompt injection and model instruction hierarchy.
   - Later topics needed: permissions, approval workflows, policy checks.

2. Agentic Framework Selection
   - Learn first: what LLMs can and cannot do.
   - Later topics needed: agent orchestration frameworks and tradeoffs.
