# 📘 Glossary

---

## 🤖 Core LLM Concepts

| Term | Definition |
|---|---|
| **LLM** | Large Language Model. A model that generates text by predicting tokens. |
| **Token** | A small unit of text processed by the model. |
| **Context window** | The maximum text the model can consider in one request. |
| **Prompt** | The instruction or input given to the model. |
| **System prompt** | A higher-priority instruction that defines behavior or rules. |

---

## 🧠 Model Architecture

| Term | Definition |
|---|---|
| **Embedding** | A numeric representation of text meaning. |
| **Transformer** | The neural network architecture used by most modern LLMs. |
| **Attention** | A mechanism that helps the model focus on relevant tokens. |

---

## 🔎 Quality and Grounding

| Term | Definition |
|---|---|
| **Hallucination** | A confident but wrong or unsupported model output. |
| **Grounding** | Making the model answer using trusted external information. |
| **RAG** | Retrieval-Augmented Generation. A pattern where relevant information is retrieved and added to the model context before answering. |

---

## ⚙️ Inference and Performance

| Term | Definition |
|---|---|
| **Inference** | Running the model to produce an answer. |
| **Latency** | How long the user waits for a response. |
| **Throughput** | How many requests the system can handle over time. |
