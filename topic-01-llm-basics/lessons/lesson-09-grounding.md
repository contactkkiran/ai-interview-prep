## 11. What is grounding?

### 🧭 Core Idea

Grounding means forcing the model to base its answer on trusted information.

### 📚 Grounding Sources

- Retrieved documents
- Database records
- Tool outputs
- Verified sources
- Citations

### 🔄 Grounding Flow

- Database
- API
- Documents
- Knowledge Graph
- Search
- Tools

RAG is one common grounding technique.
