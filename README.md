# 🤖 AI Interview Prep

## 🌟 Overview

This repository is a structured learning and practical preparation guide for AI Engineer interviews.

The goal is not to memorize interview answers or learn frameworks superficially.

### 🎯 The goal is to:

- 🧠 Understand AI concepts from first principles.
- 🔧 Connect concepts to real-world engineering problems.
- 🏢 Study realistic company interview questions.
- 🏗️ Understand high-level production architectures.
- ⚙️ Build practical implementations.
- 🎤 Develop the ability to explain and defend technical decisions in interviews.

---

## 🚦 How to Use This Repository

### ▶️ Start with:

1. 📄 Open `today.md`.
2. 📚 Follow only today's learning steps.
3. ✍️ Complete the related practice.
4. 🧠 Review the relevant interview questions.
5. 🛠️ Build the practical implementation when the topic reaches that stage.
6. ⏭️ Do not jump ahead until the current topic feels comfortable.

### 🔄 The learning approach is:

```text
Learn
  ↓
Understand
  ↓
Practice
  ↓
Interview Question
  ↓
Architecture
  ↓
Implementation
  ↓
Evaluate
  ↓
Explain
```
